DATASET RULES
-------------
1. The current source images are in:
   Indian_bovine_breeds/Indian_bovine_breeds/<breed>/<image-file>

2. The current metadata file is:
   bovine_breeds_metadata.csv

3. The metadata columns are:
   image_id, breed, path, file extension

4. The breed folder name must match the metadata breed label.

5. Raw images must not be edited directly.

6. Processed files go in data/processed/.

7. Train, validation, and test manifests go in data/splits/.

8. Generated audit results and metrics go in reports/.

9. Model checkpoints go in artifacts/checkpoints/.

10. The current dataset has not been moved into data/raw/images/. That folder is
    reserved as the future canonical location.
